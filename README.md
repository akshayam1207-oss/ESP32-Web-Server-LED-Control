# 🌐 ESP32 Web Server LED Control

### Task 1 | IoT & Connectivity

## 📌 Project Overview
This project demonstrates controlling the built-in LED of an ESP32 development board through a web interface using Wi-Fi.

## 🎯 Objectives
- Understand ESP32 Wi-Fi connectivity.
- Learn the basics of a web server.
- Control hardware through a browser.

## 🛠️ Components Required
- ESP32 development board
- USB cable
- Computer with Arduino IDE
- Wi-Fi network

## 💻 Technologies Used
- Arduino IDE
- Embedded C++
- ESP32 Wi-Fi
- HTTP web server
- HTML and CSS

## ⚙️ How It Works
1. The ESP32 connects to a Wi-Fi network.
2. It starts a web server.
3. The user opens the ESP32 IP address in a browser.
4. The user clicks ON or OFF to control the LED.

## 🚀 How to Run
1. Install Arduino IDE and ESP32 board support.
2. Open the `.ino` file from the `src/` folder.
3. Configure your Wi-Fi credentials.
4. Upload the code to the ESP32.
5. Check the IP address in the Serial Monitor.
6. Open that IP address in a browser on the same Wi-Fi network.

## 🔒 Security
Never publish your real Wi-Fi password in a public repository.
